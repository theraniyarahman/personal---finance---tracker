# 📊 Personal Finance Tracker

A simple and user-friendly Python console application to track income and expenses, calculate total savings, and generate a clear financial summary.

---

##  Features

-  Add multiple income entries  
-  Add multiple expense entries  
-  Continuous input using loops  
-  Input validation for user responses  
-  Calculates:
  - Total Income  
  - Total Expenses  
  - Net Savings  

---

##  Technologies Used

- Python  
- Loops  
- Conditional Statements  
- User Input Handling
